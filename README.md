# Student Management Console

A simple C# console-based Student Management System built using an in-memory `List<Student>`.

## Features

- Add Student
- List All Students
- Find Student by Roll Number
- Update Student Name and Marks
- Delete Student
- Search Student by Name
- Sort Students by Marks
- Input Validation
- Basic Error Handling

## Technologies

- C#
- .NET
- LINQ
- Collections
- OOP
- Console Application

## Concepts Practiced

- Classes and Objects
- List<T>
- CRUD Operations
- switch-case
- Loops
- LINQ
- Where()
- OrderBy()
- FirstOrDefault()
- Basic Input Validation
- Exception Handling

## Project Type

Console Application

## Purpose

This project was created to practice C# CRUD operations, collections, LINQ, OOP, and basic application logic before moving into ASP.NET Core development.
